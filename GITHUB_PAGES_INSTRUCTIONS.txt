How to publish this website on GitHub Pages

1. Copy index.html and style.css into the root of your final submission repository.
2. Keep your existing Images folder in the same root directory.
   Example:
      index.html
      style.css
      Images/FinalIntegrated.jpg
      Images/blockDiagram.png
3. Commit and push:
      git add index.html style.css Images
      git commit -m "Add final project website"
      git push origin main
4. On GitHub, open the repository.
5. Go to Settings -> Pages.
6. Under Build and deployment:
      Source: Deploy from a branch
      Branch: main
      Folder: / (root)
7. Click Save.
8. Wait a few minutes. GitHub will show your website URL.

If an image does not appear, check that the file name and capitalization exactly match the path in index.html.
